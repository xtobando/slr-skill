# Search and ranking

1. Derive distinct concept groups from the research question. Include named methods, synonyms, acronyms, spelling variants and relevant controlled vocabulary when verified. Use OR within groups and AND across groups when supported. Start broad enough to preserve recall. Avoid adding outcomes or NOT exclusions without checking known relevant studies.
2. Run `{SLR} search-providers`. Translate each query separately and use `{SLR} --project PATH search-literature PROVIDER --query QUERY --max-results 100 --max-requests 20 --dry-run`. PubMed supports `[Title/Abstract]` and date tags. arXiv supports `ti:` and `abs:`. DBLP and Crossref use their own relevance/term syntax. Use the exact field and date syntax the selected provider supports, and record limits applied outside the provider. Pilot against user-verified seed records; a seed check is a recall diagnostic, not a sensitivity estimate for the entire corpus.
3. Execute the authorized bounded plan without dry-run. Save exact query, interface, timestamp, counts, and truncation/stop reasons. Provider estimates can overlap. Anonymous paging restrictions and optional key access differ by provider. For an interrupted run, use `--resume --run-id RUN_ID` with unchanged provider and query and appropriate cumulative budgets. Keep failed or truncated runs visible. Use a new ID for a changed query.
4. For a discovery shortlist, run `{SLR} --project PATH rank-papers --manifest PATH_TO_MANIFEST --query QUESTION --output PATH_TO_RANKING_JSON`. Repeat `--manifest` for multiple bundles. This groups exact DOI matches or matching provider IDs when no DOI exists. For a review, run approved imports and `deduplicate` first, then rank without `--manifest` to get workbench record IDs. Select `--backend ollama --model MODEL` for a configured local service; FastEmbed is the default. Scores are cosine similarities. Preserve unscored records and use rank as queue priority.
5. For backward and forward citation expansion, verify the seed's OpenAlex ID and run `{SLR} --project PATH snowball W1234 --direction both --limit 100`. Inspect each round and child manifest. Import forward/backward results separately as citation searches under an approved source with `limits.api_provider: openalex`; the seed lookup supplies provenance. Missing or capped links are not exhaustive coverage.
6. In a formal review, import the exact successful manifest with `{SLR} --project PATH import-search MANIFEST --source SOURCE_ID`, where the source is already in the approved protocol. For manual exports, map real records to JSON or CSV and use `import-records` with actual source, run ID, query, time and truncation status. Run `search-coverage`, `deduplicate`, and `duplicate-candidates`. Review ambiguous matches individually.

Expand `{SLR}` to the locked uv command in [setup](setup.md), or its documented Python fallback. For FastEmbed ranking, add the optional `--with` dependency as described there. Resolve all other relative paths from the review workspace.
