# Retrieve and inspect PDFs

- Follow reliable full-text links and verify title, authors and DOI or preprint identifier. For a known arXiv ID or PMCID, run `{SLR} --project PATH fetch-pdf --arxiv ID --output NEW_FOLDER` or substitute `--pmc PMCID`. The supported public repository download preserves a source URL, byte count, and SHA-256 receipt. Use a user-supplied authorized copy for other sources or an unavailable direct download. Keep non-retrieval separate from scientific exclusions.
- Run `{SLR} --project PATH read-pdf ORIGINAL.pdf` for native text and physical page markers. Use `--visual` for archived original, page-linked Markdown, per-page PNGs, candidate crops and a manifest. Use `--crop PAGE X0 Y0 X1 Y1` for an additional crop, where PAGE is one-based and coordinates are unrotated PDF points from the top-left. Keep assets beside the visual Markdown so its relative links resolve.
- Inspect the cited full page and relevant crop with the runtime's image tool before interpreting equations, axes, tables or figure labels. Crops are heuristic. Preserve an image reference if editable transcription is uncertain. For scanned or incomplete pages, use an authorized OCR workflow or record missing evidence and request manual inspection.
- For formal review, verify identity, then attach the original using `{SLR} --project PATH attach REPORT_ID ORIGINAL.pdf --kind pdf` and attach the page-anchored text Markdown using `--kind markdown`. Keep the visual bundle as a workspace artifact. Reference its page and file in the evidence notes. When a figure-only claim has no matching validated text quote, describe it as a visual observation for human review and defer any structured claim the evidence schema cannot validate. Use the packet's document IDs and physical page anchors for formal evidence.

Expand `{SLR}` to the locked uv command in [setup](setup.md), or its documented Python fallback. Resolve all other relative paths from the review workspace.
